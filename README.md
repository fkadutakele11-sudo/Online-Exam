# Online Exam and Assessment System for Debre Tabor university

A web-based online examination platform designed to manage students exams, and grading securely. Developed as a fourth-year software project.
## 👨‍💻 Developed by
* **Fkadu Takele** (Computer Science Student)

## 🚀 Features
* User authentication (Admin and Student login)
* Online examination and quiz taking
* Automated score calculation
* Manage questions and exam results

## 🛠️ Technologies Used
* **Backend:** PHP, MySQL
* **Frontend:** HTML, CSS, JavaScript
* **Server:** XAMPP

## 💻 How to Run Locally
1. Clone or download this repository.
2. Move the project folder to your XAMPP `htdocs` directory (`C:\xampp\htdocs\`).
3. Start **Apache** and **MySQL** in XAMPP Control Panel.
4. Import the database (`.sql` file) via `http://localhost/phpmyadmin`.
5. Open your browser and go to: `http://localhost/onlineExam`
